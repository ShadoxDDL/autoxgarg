# AutoX – własna kopia

Repozytorium przechowuje sprawdzoną kopię dodatku `AutoX.js`.

Adres pliku po uruchomieniu GitHub Pages:

`https://shadoxddl.github.io/autoxgarg/AutoX.js`

## GitHub Pages

W repozytorium otwórz **Settings → Pages**. W sekcji **Build and deployment** ustaw:

- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** /(root)

Następnie kliknij **Save** i poczekaj na zakończenie publikacji.
